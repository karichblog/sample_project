# Giấy phép dữ liệu `data/cvdict.js`

File `cvdict.js` là bản chuyển đổi định dạng của **CVDICT – Từ điển Hán Việt** do Phong Phan biên soạn:
https://github.com/ph0ngp/CVDICT

https://creativecommons.org/licenses/by-sa/4.0/

Thay đổi so với bản gốc: đổi pinyin dạng số (xue2 xi2) sang pinyin có dấu (xuéxí), bỏ cột giản thể khi giống phồn thể, đóng gói thành một biến JavaScript để trang web tải khi cần. Nội dung nghĩa giữ nguyên.

File này (và mọi bản chỉnh sửa của nó) phải được chia sẻ theo cùng giấy phép CC BY-SA 4.0 và ghi nguồn như trên.
